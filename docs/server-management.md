# 服务器管理

服务器页集中管理 Linux 服务器：添加与分组、定时采集、首页统计与告警、
批量运维、SFTP 文件管理。采集与告警只读最新成功值：没采到、过期或失败的
数据一律显示为缺失或过期，绝不按 0 处理。

## 添加服务器

在服务器页点“添加”，填名称、主机名或 IP、端口（默认 22）、用户名与认证
方式（密码或密钥），可选跳板机、分组、标签、备注与操作系统。保存后先做
连接测试再使用：测试分三步——TCP 可达、SSH 握手、认证，失败会按网络不可达、
SSH 服务不可用、认证失败、指纹未知/变化、跳板机失败等分类说明原因。

凭据只存引用：密码与密钥口令保存在应用保险库里，不进服务器记录、日志与
错误信息。首次连接遇到未知主机指纹时必须人工确认；指纹与已存的不一致时
拒绝连接，不会自动信任。

## 分组与标签

分组用于归类服务器，标签用于筛选：列表可按分组、标签、操作系统、状态、
健康与告警筛选。删除分组会清空服务器上的分组引用，不删服务器。同一台
服务器可以同时属于一个分组与多个标签。

## 导入服务器

支持 CSV 与 XLSX 导入，列为名称、主机名、地址、端口、用户、认证方式、
密钥文件、分组、标签（分号分隔）、备注、跳板机（按名称匹配）与操作系统。
导入分两步：先预览（新增、跳过、失败及原因），确认后再应用。

- 出现密码类列时整批拒绝：导入不写凭据，导入后密码与密钥口令需另外设置。
- 重复按规范化 IP + 端口判定，已存在的跳过，不覆盖原有凭据、指纹与连接配置。
- 不存在的分组在应用时创建；不存在的跳板机使该行失败。
- 不提供资产导出。

## 软删除与恢复

删除服务器是软删除：记录保留，只是从默认列表隐藏，采集随之停止；之后可以
恢复，恢复后采集与模板指派继续。软删除不删除保险库里的凭据，也不删除已采
集的数据与模板指派记录。

## 采集与模板

打开服务器页后采集引擎开始工作：首轮立即全量采集，建立基线；之后按模板
周期定时采集。每一项都有自己的采集周期，默认模板的周期如下：

| 指标 | 周期 |
| --- | --- |
| 基础信息 | 24 小时 |
| CPU、内存、磁盘 IO、网络 | 1 分钟 |
| 磁盘容量 | 10 分钟 |
| 网卡、系统、Docker、连通性 | 5 分钟（网卡 30 分钟） |

一项采集失败不影响其他项，失败不覆盖上一次的成功值；一个值超过 3 倍周期
没更新即过期，界面仍显示最后成功值并标注“数据过期”，统计与告警不使用过期
值。未采集到的指标显示“—”，不显示 0。网络速率需要两次采样才能算出，首轮
只有总量、没有速率，速率留空。

模板决定每台服务器的采集周期。默认模板不可删除；自定义模板可为每种指标
单独设周期，未设置的沿用默认周期。给服务器指派模板后立即生效，指派会保存
下来，重启后恢复；把指派改回默认模板时不留多余记录。指派的模板被删除后，
该服务器自动回落到默认模板。

采集数据先缓存在内存里，每 10 秒集中写盘一次，未刷盘的新值在界面上立即可见。
这是有意的取舍：进程崩溃会丢掉最多 10 秒未刷盘的最新值，重启后这些值表现为
未采集或过期，绝不伪造；正常关闭、暂停、手动采集都会先把缓冲写盘，不丢数据。

## 首页统计与告警

总览页汇总服务器数量与在线情况、资源概况（CPU、内存、磁盘平均使用率，
只对有新鲜值的服务器计算，无有效数据时显示“暂无有效数据”）与最近 8 条异常，
并提供全部采集等快捷操作。告警中心按最新在前列出告警，可按已读与类型筛选，
点一行可定位到对应服务器，并可一键全部标为已读。

告警阈值带回滞：告警与恢复用不同的阈值，避免在临界值反复横跳。

| 指标 | 告警 | 恢复 |
| --- | --- | --- |
| CPU | ≥ 80% | < 75% |
| 内存 | ≥ 85% | < 80% |
| 磁盘 | ≥ 85% | < 80% |

磁盘按每台服务器每个文件系统独立判断。SSH 连接异常与资源采集失败也会产生
告警：SSH 宕机时采集失败是其后果，不另开事件；采集失败在该指标出现新鲜值
时恢复。过期或缺失的数据既不触发也不恢复告警。已恢复的告警保留为历史，
90 天后清理。

## 批量运维

批量运维页对一组服务器执行同一条命令：先按分组、标签或系统筛选目标并勾选，
输入命令后执行。执行前页面展示命令、目标数量与服务器清单；执行中可中止，
只重跑失败的服务器；单台失败不阻塞其他台；默认最多 20 台并发，每台失败
默认重试 1 次；输出过长会截断，只保留摘要，点击可看完整输出（截断后 32KB）。

命令执行前按 shell 结构做风险分级：

| 等级 | 含义与确认 |
| --- | --- |
| Normal | 直接执行 |
| High | 二次确认 |
| Critical | 需逐字输入“确认执行” |
| Blocked | 直接拒绝，如 `rm -rf /`、格式化、写磁盘设备、fork 炸弹 |

风险识别无法覆盖全部危险命令：变量、脚本、别名与非常见拼写都可能绕过，
执行前请自己再看一遍命令与目标清单。中止执行不保证杀死已经脱离会话的
远程进程。历史记录保留 30 天，可按服务器、时间与结果筛选、重新执行、删除，
并可导出 CSV、TXT 或 XLSX。

## SFTP

SFTP 文件管理页打开一台服务器后可浏览远程目录、上传与下载文件、新建目录、
重命名与删除。删除不是递归的：非空目录拒绝删除；上传一次只传一个文件；
下载拒绝目录。传输支持断点续传，可暂停、继续与取消；连接断开后不会自动
重拨，需要重新打开。远程主机拒绝 SFTP 子系统时会自动回退到 SCP。

## 应用密码与锁定

可以在设置里设置应用密码（至少 6 个字符）：设置后，应用闲置 15 分钟会
自动锁定，需要输入应用密码才能继续使用。锁定期间
托盘菜单只剩显示窗口与退出。

忘记应用密码无法找回：密码本身不可恢复，只能清除锁定设置后重新设置新的
应用密码。请务必记好应用密码。

## 托盘行为

默认关闭窗口时应用隐藏到系统托盘而不是退出，会话保持连接；可以在设置里
改为关闭即退出。第一次隐藏到托盘时会有一次通知说明窗口没有退出，此后不再
提示。托盘菜单列出各窗口的会话、主机与工作区，并提供新建本地终端、显示窗口、
检查更新与退出。托盘图标也可以在设置里关闭。

## 休眠恢复

睡眠或锁屏时采集暂停：不再发起新采集，排队任务丢弃，进行中的轮次以中断收尾。
唤醒或解锁后恢复：各指标的下一次执行按当前时间加周期重算，睡眠期间到期的
任务不补跑，并逐台做连通性检测以预热连接。若睡眠时没有经过暂停流程，调度器
在发现超过 10 分钟的时间缺口时同样按唤醒处理（不做连通性检测）。

## 已知限制

- 采集写盘缓冲：进程崩溃会丢掉最多 10 秒未刷盘的最新值，重启后这些值表现为未采集或过期，绝不伪造。正常关闭、暂停与手动采集都会先刷盘。
- 磁盘的设备名（Device）为空：底层采样协议不提供设备名，不填假值。
- Swap 读不到与未启用无法区分：两者都显示为未启用。
- SFTP 删除不是递归的，上传一次只传一个文件，下载拒绝目录；连接断开后需手动重新打开。
- 批量命令的风险识别无法覆盖全部危险命令；中止不保证杀死已脱离会话的远程进程。
- 批量命令输入框为单行，多行脚本需用 `;` 或 `&&` 连接。
- 批量历史单条记录受 1MB 存储上限约束：多台服务器的大输出可能导致保存失败，可调小输出截断。
- 未做真实 Linux 主机端到端验证：采集、告警、批量与 SFTP 均用假传输与本地测试服务器验证，建议在真实 Ubuntu 与 openEuler/麒麟主机上做一次冒烟验证。
- 服务器资产不同步：服务器、分组与跳板机记录不参与跨设备同步。
- 每个窗口各自启动一个采集引擎（各持一套连接）；多窗口共享引擎需另行实现。
- 终端打开目前直连目标机，不走跳板机；连接测试已覆盖跳板机。
